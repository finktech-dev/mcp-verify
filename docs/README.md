# Documentation index

This directory holds repository policy and durable operational context. Start
with the document that matches the question instead of reading every file.

| Need                                      | Canonical document                           |
| ----------------------------------------- | -------------------------------------------- |
| What exists and its support state         | `PRODUCT_STATUS.md`                          |
| Branches, commits, and pull requests      | `GOVERNANCE.md`                              |
| Publishing and release evidence           | `RELEASING.md`                               |
| Current and deferred CLI scope            | `../COMMANDS.md`, `DEFERRED_CLI_COMMANDS.md` |
| Material intentionally removed            | `REMOVED_SURFACES.md`                        |
| Durable architecture and policy decisions | `decisions/`                                 |
| Internationalization conventions          | `I18N-GUIDE.md`                              |
| LLM and storage risk boundaries           | `LLM_RISKS_AND_ARCHITECTURE.md`              |

Public usage instructions belong in the root README, package READMEs, and
`guides/`. Coding-agent context belongs in the nearest `AGENTS.md`.
